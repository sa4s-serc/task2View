
Use the uml-view skill in .claude/skills (it builds on the plantuml-diagrams skill there) and follow all its
steps. Write view.puml, view.png, inventory.json and README.md in ./view-out/{case}/.
The detail level is given in the stakeholder perspective ({detail_level}); draw at that level and run
check_inventory.py with --level {detail_level} --graph .claude/repo-graph.json.
A static dependency graph of the repository is in .claude/repo-graph.json; query it with the skill's
graph_query.py as the skill describes.
Then run check_view.py on view.puml as the skill describes and fix what it reports.
