# Architecture decisions

This folder records **design choices** for Task2View that we made in discussion and then implemented.

They are not the pipeline spec and not meeting notes. Each file is one decision (or a tightly related set). Read them when the code and the research plan seem to disagree.

| ID | Title | Status |
|---|---|---|
| [ADR-001](ADR-001-agentic-realignment.md) | Realign the running system with the research-plan multi-agent process | accepted (D5–D7 superseded) |
| [ADR-002](ADR-002-sota-plugins.md) | SOTA plug-ins for analysis; any notation for the view | accepted |

## How to add a new one

Copy the heading structure of ADR-001. Number sequentially. Link it in the table above. Do not rewrite history in an old ADR; add a new one that supersedes it.
