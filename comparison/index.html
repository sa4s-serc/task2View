The three conditions

  • Plain agent: Claude Code (Sonnet 5.5) in the repository, given the stakeholder's request and asked for architecture views as PlantUML.
  • Skill agent: the same, with the Task2View skill installed (the Views & Beyond catalogue and the method as instructions), so the agent follows the method itself.
  • Task2View: the pipeline above, run end to end.
